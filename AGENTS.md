# A3 project guidance

Standalone Next.js App Router game. Use Node 26, pnpm 10.34.7, static export and pnpm-lock.yaml only. Keep game composition in src/app, shared UI in src/components, helpers in src/utils. Install Delta through the configured registry; review updates and preserve Base UI accessibility. Preserve gameplay, equilateral triangle artwork, token-driven canvas, dark default and reduced motion. No portfolio checkout dependencies. Vercel Git integration handles builds and publishing. Run tests, lint and builds only when explicitly requested.
